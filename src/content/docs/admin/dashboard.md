# Dashboard

O Dashboard é a primeira tela ao entrar no sistema como administrador. Ele dá uma visão rápida de como o salão está indo, sem precisar abrir várias telas.

## O que você encontra aqui

![Visão geral do Dashboard, com KPIs, gráfico de receita e ranking de profissionais](/docs-images/admin-dashboard.webp)

- **KPIs do dia**: quantos atendimentos aconteceram hoje.
- **KPIs do mês**: receita total, ticket médio, número de comandas fechadas e taxa de cancelamento.
- **Gráfico dos últimos 30 dias**: evolução da receita dia a dia, pra você notar picos e quedas.
- **Top serviços**: quais serviços mais venderam no período.
- **Ranking de profissionais**: os 5 profissionais que mais geraram receita no mês, com número de atendimentos, receita gerada e comissão de cada um.

## Como usar

Não tem nenhuma ação para fazer aqui — é só leitura. Use o Dashboard para:
- Acompanhar se o mês está indo melhor ou pior que o esperado.
- Identificar rapidamente qual profissional está com mais volume.
- Ver se a taxa de cancelamento está alta (sinal de alerta).

> Se um número parecer errado, confira o período: os KPIs de mês sempre se referem ao mês corrente.
