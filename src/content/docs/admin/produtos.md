# Produtos e Pedidos

## Produtos

Cadastro dos produtos vendidos no salão (nome, preço, estoque). Serve de base para os pedidos.

## Pedidos de Produtos

Registro de vendas de produto para um cliente. Um pedido pode ficar como **encomendado** até ser pago — o pagamento é feito na aba Produtos do Caixa, ou junto com o fechamento de uma comanda de serviço.

O estoque é verificado automaticamente: se não houver quantidade suficiente, o sistema avisa e não deixa continuar.
