# Clientes

Aqui ficam todos os clientes cadastrados no sistema — tanto os que se cadastraram sozinhos pelo site quanto os que você cadastrou manualmente.

## Cadastrar um cliente

Clique em **Novo cliente** e preencha nome e telefone. A senha inicial é padrão e o cliente é obrigado a trocá-la no primeiro acesso.

## Filtros

- Busca por nome.
- Ativos / Inativos.
- Aniversariantes do mês.
- **Mensalistas** — clientes com fiado pendente (veja a página de Caixa para entender fiado).

## Painel do cliente

![Painel de detalhes do cliente com KPIs, comandas em aberto e últimos agendamentos](/docs-images/admin-clientes.webp)

Clique em qualquer linha da lista para abrir o painel de detalhes, com:
- KPIs: total de atendimentos concluídos, total gasto, ticket médio.
- Comandas em aberto, com botão para **fechar conta** direto por ali.
- Últimos agendamentos.
- Se o cliente for mensalista, uma seção mostra a mensalidade pendente com opção de pagar.

## Ativar / Desativar

O botão de ativar/desativar bloqueia o acesso do cliente ao sistema sem precisar excluir o cadastro.
