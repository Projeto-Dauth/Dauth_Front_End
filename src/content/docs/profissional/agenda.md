# Agenda

Sua agenda mostra os horários do seu dia. Ela é sua tela principal ao entrar no sistema.

## Navegação

Use as setas para trocar de dia, o ícone de calendário para pular direto para uma data, e o botão Hoje para voltar ao dia atual.

## Criar um agendamento

Clique em um horário vazio. Escolha o cliente (ou cadastre um novo na hora), o serviço (pode adicionar mais de um) e ajuste os horários se precisar. Marque **Urgente** se precisar encaixar um cliente mesmo com conflito de horário.

## Ações em um agendamento

Clique com o botão direito (ou toque e segure no celular):
- Marcar como Confirmado / Concluído / Cancelado.
- Transferir data — muda o agendamento para outro dia/horário.
- Abrir comanda — vai direto para Comandas com o cliente selecionado.
- Fechar comanda — disponível depois que o atendimento é Concluído.
- Ver detalhes.

## Folgas

Use o botão **+ Folga** para marcar um dia (ou parte dele) em que você não vai atender. Aparece como bloco vermelho na sua agenda e bloqueia novos agendamentos naquele intervalo.
