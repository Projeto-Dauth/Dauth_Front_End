# Comandas

Uma comanda é aberta automaticamente quando um atendimento acontece. Aqui você fecha a conta do cliente.

## Sub-abas

- **Serviços** — comandas de atendimentos, com o valor a receber.
- **Produtos** — pedidos de produtos vendidos ao cliente.

## Fechar uma comanda

Clique na comanda do cliente e escolha o método de pagamento. Se o cliente tiver mais de uma comanda em aberto, elas aparecem agrupadas para fechamento conjunto (inclui produtos pendentes).

## Fiado

A opção **Fiado — cobrar depois** registra o valor como pendência do cliente, sem cobrança imediata. A quitação depois é feita pelo administrador na tela de Caixa (Mensalistas).
