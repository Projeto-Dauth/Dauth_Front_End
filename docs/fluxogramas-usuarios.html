Fluxos do Cliente

Ações disponíveis para clientes cadastrados no sistema Dauth.

Acesso público (sem login)
Requer autenticação
Ação irreversível

🚀
Criar Conta

1
Preenche e-mail, nome e senha
Formulário de cadastro
UI
2
Submete cadastro
POST /auth/register
3
Login automático em seguida
POST /auth/login
4
Busca perfil completo
GET /users/perfil/me
5
Redireciona para /cliente
✓ Conta criada e autenticado
🔑
Fazer Login
Trigger: acessa /login
1
Se sessão expirou anteriormente, exibe aviso
Flag session_expired no sessionStorage → toast "Sua sessão expirou"
UI
2
Informa e-mail e senha
UI
3
Autentica na API
POST /auth/login
4
Busca perfil real do banco
GET /users/perfil/me
5
Redireciona por role (Admin/Profissional/Usuario)
✓ Sessão iniciada

Sair (Logout)
Trigger: botão sair (sidebar ou header mobile)
1
Chama endpoint de logout
POST /auth/logout

✂️ Profissional

Fluxos do Profissional

Ações disponíveis para profissionais vinculados ao salão via convite.

Requer autenticação como Profissional
Alterações aplicadas imediatamente
Onboarding (Convite)
📨
Aceitar Convite do Admin
Trigger: clica no link do e-mail
1
Admin envia convite por e-mail
Admin acessa /admin/convidar-profissional
2
Supabase envia e-mail com link único
Link redireciona para /auth/accept-invite#access_token=JWT
3
Preenche telefone, data de nascimento e senha
UI
4
Finaliza cadastro
POST /auth/accept-invite
✓ Conta ativada, redireciona para /profissional
⚠️ O link de convite é de uso único. Tokens JWT do hash são lidos apenas uma vez.

3
Exibe now-card (atendimento atual), próximos e grade de horários
UI
📋
Minha Agenda (lista)
Trigger: acessa /profissional/agendamentos

2

UI (filtros)
3
Clica para ver detalhes
Redireciona para /agendamento/:id
Serviços Vinculados
✂️
Gerenciar Serviços Próprios
Trigger: acessa /profissional/servicos
1
Carrega catálogo completo de serviços
GET /service
2
Para cada serviço, verifica se está vinculado
GET /service/:id/professionals
3a
Vincular serviço
POST /service/:id/professionals
✓ Aparece no agendamento público
3b
Desvincular serviço
DELETE /service/:id/professionals/:linkId
⚠ Serviço deixa de aparecer para agendamento
Horários de Trabalho
⏰
Configurar Horários Semanais
Trigger: acessa /profissional/horarios
1
Carrega horários cadastrados
GET /working-hours/professional/:id
2a
Adicionar horário para um dia da semana
POST /working-hours
Body: { professional_id, weekday (0–6), start_time, end_time }
2b
Editar horário existente
PATCH /working-hours/:id
Body: { start_time, end_time }
2c
Remover horário de um dia
DELETE /working-hours/:id
⚠ Bloqueia novos agendamentos naquele dia

Fluxos do Administrador

Ações completas de gestão do salão disponíveis para administradores.

Ação crítica / irreversível
Requer autenticação como Admin
Afeta fluxo de outros usuários
Agenda & Agendamentos
📅
Agenda Geral (Grade por Profissional)
Trigger: acessa /admin
1
Carrega profissionais (colunas fixas)
GET /users?Role=Profissional
2
Carrega agendamentos do dia selecionado
GET /appointment?date=YYYY-MM-DD
3
Navega entre dias (← →) para ver agenda de outros dias
UI
📋
Gerenciar Agendamentos
Trigger: acessa /admin/agendamentos
1
Lista todos os agendamentos
GET /appointment
2
Filtra por data ou status
UI (filtros)
3
Abre detalhes e altera status
PATCH /appointment/:id
Body: { Status: 'confirmado' | 'cancelado' | 'concluido' }
✓ Status atualizado — visível ao cliente e profissional
Caixa & Pagamentos
💰
Registrar Pagamento de Comanda
Trigger: acessa /admin/caixa
1
Lista comandas abertas
GET /tab
2
Abre painel de pagamento da comanda selecionada
UI
3a
Se comanda tem valor (serviço pago): registra transação
POST /transaction
Body: { Payment_date: ISO8601, ... }
3b
Se comanda é uso de combo (Value=0): sem transação
Apenas atualiza status
4
Fecha a comanda
PATCH /tab/:id
✓ Comanda fechada

1
Preenche nome, preço e validade

2

Body: { Service_id, Quantity }

🛒
Vender Combo para Cliente
Trigger: botão Vender no card do combo
1

UI (busca de cliente)
2

POST /package/:id/sell
Body: { Client_id }
✓ Combo aparece em "Meus Combos" do cliente
🗑️
Editar / Excluir Pacote
Trigger: ações no card do combo
E
Editar informações do pacote
PATCH /package/:id
R
Remover item do pacote
DELETE /package/:id/items/:itemId
X
Excluir pacote inteiro
DELETE /package/:id
✕ Ação irreversível
